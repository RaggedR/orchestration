# Theoretical Foundations: Signed Fingerprint Functoriality

## Status

We have experimental results (6/8 domains, W = 0.91, Cohen's d up to -14.8) and an intuitive explanation (left Kan vs right Kan adjunction). We do not yet have a formal theory. This document records what a theory would need, where the gaps are, and what we conjecture.

## What We Have

### Experimental Result

Migration topology determines LLM agent solution diversity, with the ordering **inverted** from GAs:

```
GA:  none > ring > star > fully_connected   (Kendall's W = 1.0, 6 domains)
LLM: fully_connected > ring ≈ star > none   (Kendall's W = 0.91, 6/8 domains)
```

The effect requires:
1. The model's prior distribution is **peaked** (None diversity < 0.10)
2. The solution landscape is **multi-modal** (FC/None ratio > 2)

When either fails (bloom_filter: unimodal; expression_eval: prior already diverse), the effect weakens or inverts.

### Intuitive Explanation

GA migration is a **left Kan extension** along the topology graph (colimit-like: merges populations → homogenizes). LLM "be different" context is a **right Kan extension** (limit-like: accumulates constraints → diversifies). The adjunction Lan ⊣ Ran flips the sign of the diversity effect.

## What a Theory Requires

### 1. A category of LLM solution distributions

**For GAs (established in the paper):**
- Objects: population types Pop(Σ)
- Morphisms: Kleisli arrows Pop(A) → T(Pop(B)) over the evolution monad T = Reader(Γ) × Writer(Λ) × State(S)
- Composition: Kleisli composition, associative by the monad laws

**For LLMs (needed):**
- Objects: probability distributions over solution strings, or more tractably, probability measures on the embedding space ℝⁿ (where n = embedding dimension, e.g. 384 for all-MiniLM-L6-v2)
- Morphisms: context-augmentation maps. Given distribution D and context string c, produce D|c — the model's output distribution conditioned on seeing c in the prompt
- Composition: augmenting with c₁ then c₂ should equal augmenting with (c₁, c₂). This is plausible but not exact — positional effects in the context window mean order matters. Might need to work up to ε-equivalence, connecting to Ghani et al.'s approximate game theory (already cited in the paper)

**Working in embedding space** rather than string space sidesteps tokenization issues and gives a metric space where cosine distance is well-defined. Distributions become measures on ℝⁿ, and diversity becomes a functional on measures.

### 2. Formal definition of coupling sign

Let G be a topology graph (the migration/context-sharing structure), **Sol** the category of solution distributions, and F: G_partial → **Sol** a partial assignment (solutions already generated by some agents).

- **Left Kan extension** Lan_G F: extends F to all agents by interpolation. The value at an unassigned agent is the colimit — a "blend" of the assigned neighbors' solutions. Morphism: "produce something consistent with your neighbors." Effect: homogenize.

- **Right Kan extension** Ran_G F: extends F to all agents by constraint. The value at an unassigned agent is the limit — the "most general" solution satisfying all constraints from neighbors. Morphism: "produce something compatible with but distinct from your neighbors." Effect: diversify.

The adjunction Lan_G ⊣ Ran_G is a standard result in category theory (pointwise Kan extensions exist when **Sol** has the necessary (co)limits). The sign flip follows: Lan and Ran are adjoint functors, and adjoint functors reverse inequalities in any poset they act on. If diversity is a poset-valued invariant, the adjunction reverses its ordering.

**Gap**: we need to show that diversity (mean pairwise cosine distance) is monotone with respect to the Lan/Ran action on distributions. This is the core technical claim.

### 3. Signed functoriality (the main conjecture)

**Conjecture.** Let D: Kl(T) → ℝ be the diversity fingerprint functor from the paper's Proposition 1. Let F: Kl(T_GA) → Kl(T_LLM) be a domain-change functor from GA pipelines to LLM agent pipelines. If the coupling mechanism in Kl(T_LLM) is the right adjoint of the coupling mechanism in Kl(T_GA) (i.e., Ran instead of Lan along the topology graph), then:

```
D(F(σ)) = -D(σ) + constant
```

up to normalization. That is, the diversity ordering reverses while the monotonicity (the ordering being total) is preserved.

**Stronger form**: for any topology graph G, let λ₂(G) be its algebraic connectivity (second eigenvalue of the Laplacian). Then:

- Under left Kan coupling: D is monotonically decreasing in λ₂
- Under right Kan coupling: D is monotonically increasing in λ₂

The topology ordering is an invariant of the graph spectrum; the direction depends on the adjoint.

### 4. Landscape precondition, categorically

The anti-functor requires the solution landscape to have structure for the topology to act on. Candidates for formalizing this:

**Topological**: the superlevel sets of the model's output distribution on embedding space have Betti number β₀ > 1 (multiple connected components = multiple algorithmic modes). The distribution's mass is concentrated on one component (peaked prior). Negative coupling pushes agents onto the other components.

**Information-theoretic**: let H(D_none) be the entropy of the model's output distribution under no context (none topology). Let H(D_FC) be the entropy under full negative coupling. The anti-functor fires when:
- H(D_none) is low (peaked prior)
- H(D_FC) - H(D_none) is large (coupling unlocks latent entropy)

**Metric**: in Leinster's diversity framework (cited in the paper), diversity is a function of the pairwise similarity matrix Z. The precondition is that Z under the none topology is nearly rank-1 (all solutions similar) but the solution space contains well-separated clusters that the none topology fails to reach.

**Connection to GA landscape analysis**: the paper's `Evolution.Landscape` module computes ruggedness, correlation length, neutrality, and local optima via random walk. The LLM equivalents:
- **Ruggedness** ↔ how much the model's output changes when the prompt changes slightly
- **Correlation length** ↔ how many context examples before the output distribution stabilizes
- **Neutrality** ↔ fraction of context augmentations that don't change the output
- **Local optima** ↔ number of distinct algorithmic modes in the output distribution

The "None probe" (5 isolated samples) measures a combination of these. The FC/None ratio measures the landscape's response to maximal coupling.

## Concrete Next Steps Toward Theory

1. **Formalize in Haskell.** Define `AgentOp HarnessM String String` where the monad wraps the LLM API call. Implement left-coupling ("build on this") and right-coupling ("be different") as two different `syncAgents` functions on the same topology. Use QuickCheck to test composition laws numerically.

2. **Prove diversity monotonicity.** Show that mean pairwise cosine distance is monotone with respect to the Lan/Ran action. This might require restricting to a specific class of distributions (e.g., mixtures of Gaussians on the embedding space).

3. **Foster census experiment.** Run the experiment on the 13 cubic arc-transitive graphs, where λ₂ is computed exactly via GAP. Plot diversity vs λ₂. If the relationship is monotonic, that's strong evidence for the spectral characterization.

4. **Flip the coupling sign.** Re-run the experiment with "build on and improve this approach" instead of "use a different algorithm." If the ordering reverses back to match the GA paper, that confirms the adjunction hypothesis directly. Same topology, same tasks, one prompt change.

5. **Topological landscape analysis.** Compute persistent homology of the embedding-space point clouds from the None topology. Check whether β₀ (number of clusters) predicts which tasks show the anti-functor effect.

## Open Questions

- Does the signed laxator generalize beyond LLMs? E.g., a GA with "novelty-seeking migration" (remove similar individuals upon migration) should also invert the ordering.
- What predicts the Cohen's d gradient across tasks? Is it purely the entropy of the model's prior, or does the embedding geometry matter?
- The paper's open problem (braided monoidal structure for adaptive strategies) — does expression_eval's inversion have a braided interpretation?
- Can the landscape precondition be unified with Leinster's maximum diversity theorem?
